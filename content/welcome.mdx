# Welcome

Welcome to the **Next.js MDX Playground**!

This is an example of MDX content stored in the `/content` folder.

## What is MDX?

MDX lets you use JSX in your markdown content. You can import components and embed them within your content.

## Getting Started

1. Create `.mdx` files in the content folder
2. Import them into your pages
3. Render them as React components
